# RP Gaming Assistance · 遗传性视网膜色素变性游戏辅助

> 「罕见·无界」黑客松赛题 · 项目6：遗传性视网膜色素变性 + 游戏辅助工具
> 由 [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)发起 · 患者共创 · 一个赛题 = 一个长期开源项目

为遗传性视网膜色素变性（Retinitis Pigmentosa, RP）玩家打造游戏辅助方案，让逐渐失去视野的玩家依然能享受游戏的乐趣。

## 🧭 背景与真实处境

遗传性视网膜色素变性（RP）是一组遗传性视网膜营养不良疾病，会带来**进行性的视野缩窄（管状视野）与夜盲**。玩家在主流游戏中面临目标发现困难、界面信息难以辨认、暗场景几乎不可见等障碍，而大部分游戏缺乏针对低视力玩家的辅助选项——游戏不仅是娱乐，更是 RP 患者社交、放松与自我表达的重要途径。

## 🎯 挑战方向

- **画面辅助渲染**：高对比度 / 大字号 / 局部放大 / 关键目标高亮等画面增强方案
- **听觉替代视觉**：以音效 / 语音导航提示方位、距离、事件等关键信息
- **低成本、可 DIY**：兼容主流游戏与外设的辅助方案（外挂式工具、改版客户端、配置分享等）

## 📌 项目状态
