# RP Gaming Assistance · 遗传性视网膜色素变性游戏辅助

> 项目6：遗传性视网膜色素变性 + 游戏辅助 —— [OpenRD 罕见病开源社区](https://github.com/OpenRDHub)

为遗传性视网膜色素变性（Retinitis Pigmentosa, RP）玩家打造游戏辅助方案。

## 真实处境

遗传性视网膜色素变性（RP）会带来进行性的视野缩窄与夜盲，玩家在主流游戏中面临目标发现困难、界面信息难以辨认、暗场景几乎不可见等障碍，而大部分游戏缺乏针对低视力玩家的辅助选项。

## 挑战方向

- 游戏画面高对比度 / 大字号 / 局部放大等辅助渲染方案
- 基于听觉替代视觉的关键信息提示（音效 / 语音导航）
- 兼容主流游戏与外设的低成本、可DIY方案
