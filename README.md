# Full-Screen Map Awareness for Low-Vision Gamers · 为视力障碍玩家打造识别全屏地图的工具

> 「罕见·无界」黑客松赛题 · 项目6：遗传性视网膜色素变性 + 游戏辅助工具
> 共建发起者：Hero（RP 患者）· [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub) · 一个赛题 = 一个长期开源项目

为视网膜色素变性（RP）等视力障碍玩家打造**实时识别并"翻译"全屏地图信息**的游戏辅助工具，弥补"视野狭窄"带来的信息盲区。

## 🧭 疾病背景：视网膜色素变性（RP）

RP 是一种遗传性、进行性的视网膜退行性疾病，是最常见的遗传性致盲眼病之一：

- **核心症状**：夜盲（最典型的早期症状）；进行性视野缩小——视野逐渐向中心收缩形成**管状视野**，"仿佛通过一根吸管在看世界"；部分患者到中年时中心视力也会严重受损甚至失明
- **流行病学**：全球患病率约 1/4000，中国约有超过 100 万名患者
- **遗传特点**：高度遗传异质性，已发现超过 100 个相关致病基因
- **致病机理**：视网膜感光细胞（视杆→视锥）进行性凋亡，视杆细胞（暗视觉 + 周边视觉）首先受累
- **治疗现状**：尚无有效治愈方法；基因治疗（如 Luxturna）、细胞治疗、人工视网膜等仍在临床研究阶段

**RP 对玩家"视野"的具体影响**：视野狭窄——只能看到屏幕中心一小块，屏幕边缘的敌人靠近、队友信号、技能特效完全无法察觉；昏暗场景（洞穴、夜晚地图）操作困难加剧；快速移动目标难以追踪；放大镜/读屏软件要么破坏沉浸感、要么跟不上实时操作。

## 👤 用户画像与核心需求

**Hero 本人**：RP 患者，视野严重缺失，中心残余视力仅 **0.01**——但仍是一名希望继续游玩**主流商业游戏**的游戏爱好者。

**核心需求**：一款工具，能实时读取并"翻译"玩家视野之外的屏幕地图信息（尤其是周边视野中的关键动态），以用户可感知的方式——**语音播报、震动提示、边缘光效**等——反馈给玩家。

**典型使用场景**：

| 场景 | 游戏 | 挑战 |
|---|---|---|
| MOBA | 王者荣耀 | 只能感知角色周围极有限画面，屏幕边缘的战场动态完全不知道 |
| FPS/吃鸡 | 和平精英 | 全局态势感知要求高，听声辨位与视野缺一不可，RP 玩家两方面都受限 |
| 休闲益智 | 开心消消乐 | 看似简单，同样依赖全局视野规划策略 |
| 开放世界 RPG | 原神 | 信息密度极高、地图广袤、元素繁多 |

## 📉 已经试过的方案，以及为什么都不够好

以下均为发起者 Hero 的真实尝试经验：

1. **大屏幕/平板放大** —— 反而更糟：画面元素等比放大，"用一根吸管看一个更大的世界"，信息盲区更大。**放大不能解决问题：患者需要的不是"看得更清楚"，而是"知道周围发生了什么"。**
2. **助盲音频游戏** —— 可玩性单一，且是最致命的：朋友都在玩主流游戏，音频游戏是另一座"孤岛"，无法一起开黑、社交，反而加剧孤独感。**"无障碍"不等于"好玩"，更不等于"能和朋友一起玩"。**
3. **调整游戏内设置**（亮度/对比度/FOV/小地图）—— 只能优化"看得怎么样"，无法解决"看得到哪里"。
4. **屏幕放大镜/辅助软件** —— 进一步压缩本已狭窄的视野，MOBA/吃鸡类全局游戏里几乎"自废双眼"，画面频繁移动还会眩晕。

## ⚖️ 赛手一定要知道的设计铁律

- **患者不是"看不见"，而是"看得太少"**：重点是"如何在不遮挡仅存视野的前提下，高效传递关键信息"
- **"不遮挡视野"是铁律**：任何 UI、提示弹窗都不许占据用户仅存的中心视野；提示音、震动、边缘光效、骨传导等不依赖视力的交互可能更有效
- **实时性的极致要求**：报点比画面慢 0.5 秒，玩家可能已经"成盒"了——方案必须极低延迟
- **"提示"不等于"代替思考"**：提供辅助（"左侧有敌人"），而不是替代决策（"自动开火"）
- **自定义与灵活性**：残余视力、视野大小、游戏偏好因人而异，提示频率/方式/详略/音色音量都应可调
- **兼容性是关键**：患者玩的是市面商业游戏，方案最好是**通用的外挂式工具**，从屏幕画面实时提取信息，不依赖特定游戏引擎或 API，不要求游戏改变
- **隐私与尊严**：玩家不希望因使用辅助工具而被歧视或区别对待——把它做成"谁都想要的外挂"，只是它助力的是真正的玩家
- **技术与伦理边界**：遵守游戏厂商服务条款；聚焦"读取信息、理解信息、翻译呈现"，而非"自动操作游戏"，避免被判定为作弊程序
