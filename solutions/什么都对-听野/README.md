## 解决什么问题

视野狭窄的玩家难以持续观察屏幕边缘、小地图和完整棋盘。单纯放大画面可能进一步减少同时可见的范围，通用读屏也难以跟上实时对局。

听野将画面中已经可见、但玩家不易及时察觉的信息转为可听、可感知的提醒，减少反复寻找和记忆的负担。玩家始终自行判断并完成游戏操作。

## 主要功能

| 场景 | 当前实现 |
| --- | --- |
| 王者荣耀 | 在手机本地识别小地图中的可见敌方信息，经筛选、排序、去重后提供附近敌人与方位提醒；核心预警不依赖网络。 |
| 开心消消乐 | 识别与确认棋盘，提供交换建议，通过语音和视觉高亮帮助定位棋子；在目标与规则能够可靠确认时，根据已确认的任务贡献排序。 |
| 声音与触觉 | 提供提示音、语音和振动，并支持语速、音量及提醒偏好设置；固定提示使用内置离线语音，消消乐动态语音依赖手机可用的中文 TTS 引擎。 |
| 大字与帮助 | 页面适配系统字号，分组展示说明；首次引导和帮助内容支持按段听取。 |
| 可选游戏助手 | 默认关闭，用户开启并授权后可进行语音交流和画面问答；即时战局提醒使用本地预警，云端回答的速度和准确性继续验证。 |

交换建议不保证所有局面中的最优解，接近提醒也不能预知隐藏敌人或技能。未可靠识别的内容不作为确定事实或确定收益呈现。

## 技术方案

```text
Android 屏幕采集（MediaProjection，逐次授权）
  → 本地图像识别（Android / C++ / ncnn）
  → 事件筛选、优先级、去重与冷却 / 棋盘规则与交换建议
  → 提示音、语音、振动、视觉高亮
  → 玩家自主操作
```

- Android 应用负责权限、界面、屏幕采集、提示调度及语音呈现。
- C++ 与端侧模型负责小地图识别；棋盘识别与规则逻辑用于消消乐辅助。
- Python 工具用于诊断、回放、数据处理与评测，并提供可选画面助手的服务端网关。
- 本地预警与云端助手分别运行。不开启助手也可以使用核心本地辅助功能。

## 如何试用与演示

1. 使用 Android 10 及以上的 arm64 手机，从公开发布页下载安装包。
2. 打开听野，选择「王者荣耀」或「开心消消乐」，先试听声音并调整音量、语速和提醒偏好。
3. 点击开始辅助，按应用提示授权屏幕采集；需要交换高亮时，按提示授予悬浮显示权限。
4. 在对应游戏内观察并体验提醒，所有交换、移动和其他游戏操作均由玩家完成。
5. 结束后停止辅助。如遇错误提醒、没有提示或明显发热，可通过项目 Issues 反馈复现步骤；诊断材料应先去除个人信息，再通过团队认可的渠道提供。

本项目需要真实 Android 设备与对应游戏。魔搭 Demo 与官网提供项目介绍、交互和声音示意，APK 用于实际试用；网页示意不替代 Android 上的真实屏幕识别与辅助。

## 从源码构建

完整配置和素材要求见[项目 README](https://github.com/ld0574/SenseField#开发与构建)。准备 JDK 17、Android SDK / NDK 后，在源码仓库中运行：

```sh
git clone https://github.com/ld0574/SenseField.git
cd SenseField/android
./gradlew assembleDebug
```

模型权重等运行素材未全部纳入 Git，需要按源码仓库中的 metadata 与开发说明准备对应文件。干净克隆与编译成功不代表已具备全部识别和语音素材；正式发布另需按项目说明配置签名。

## 隐私、使用边界与开源许可

- 不注入游戏、不读取游戏进程或内存、不模拟触控、不代替玩家操作。
- 核心本地预警不上传画面。可选画面助手在用户开启并授权后，将问题文字及必要截图经 HTTPS 发送至服务端与视觉模型；截图可能包含聊天或通知，使用前应留意授权范围。
- API 密钥保留在服务端，患者个人信息、原始录像、诊断截图和私有实验材料不纳入本次提交。
- 本方案是游戏无障碍辅助工具，不提供医疗诊断或疗效承诺。项目为非官方作品，游戏名称、商标与内容归相应权利人所有。
